# Idea To Music

REDESIGN THE LANDING PAGE FROM SCRATCH.

The previous version looks like a blog/editorial website.

That is NOT what we want.

This is a HIGH-CONVERTING SALES LANDING PAGE for a low-ticket music production offer.

The page must immediately feel like an offer.

R$67

"Sua ideia vira uma música profissional."

Keep this path easy to change.

Video:

Subtle shadow
